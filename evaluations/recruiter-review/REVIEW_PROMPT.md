# Independent recruiter review prompt

Review this public repository as an AI/LegalTech recruiter with no access to prior conversation. Identify every material claim, locate its evidence, classify it as verified, self-declared, inferred, or unsupported, and assess legal relevance, reproducibility, authorship transparency, responsible-AI controls, and navigation. Do not treat a repository statement as proof without following its evidence link. Do not infer Microsoft certification or an official grade. Report critical blockers, score the repository-readiness rubric, and give a publish/no-publish decision.

Run `python scripts/run_checks.py`. Write the results to `REPORT.md` and `report.json` using the rubric dimensions and distinguish repository QA from any academic or vendor assessment.
