# Document Facts

Define the fields or comparison question before extraction. Preserve a source pointer for each result, distinguish missing from unclear, and quote only the minimum text needed for audit. Normalize dates, amounts, and names only in separate fields; keep the original value. Never infer a legal conclusion from a missing field. Flag conflicting versions and unreadable content. Use only public, synthetic, de-identified, or authorized documents. Return a compact table plus an exceptions list for human review.
